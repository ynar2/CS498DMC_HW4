This project implements a data processing and web service pipeline using a GCP VM (Ubuntu 22.04), Neo4j for graph data modeling, PySpark for distributed data preprocessing, and a Flask API to serve backend endpoints.

Repository Structure:
clean.py: Downloads and cleans the taxi dataset, reducing it to 10,000 valid records.
load_graph.py: Loads clean taxi trip data into Neo4j graph database.
preprocess.py: Processes data using PySpark to compute company summaries and writes to processed_data/.
app.py: Flask API server exposing endpoints for graph queries and Spark summaries.
fdb_answers.txt: Conceptual questions and answers for FoundationDB architecture.

API Endpoints:
GET / - Health check.
GET /api/drivers/<driver_id>/company - Returns company name for a given driver ID.
GET /api/companies/<company_name>/revenue - Returns total revenue generated by a company.
GET /api/spark/summary - Returns precomputed Spark summary data from processed_data/.
